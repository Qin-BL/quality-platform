# workspaces/ — Multi-Repository AI Delivery Workspaces

This directory holds workspace definitions for AI-driven development workflows
that span multiple repositories.

Unlike `projects/`, which model QC execution space for one product surface,
`workspaces/` model delivery orchestration:

- repository inventory
- branching strategy
- repo-specific build/test commands
- environment and deployment mapping
- framework mirror configuration
- repo-scoped planning and agent-session artifact generation
