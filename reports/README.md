# reports/ — QC Report Archives

This directory stores QC execution reports organized by type.

## Report Types

| Directory | Content |
|-----------|---------|
| `qc/` | Full QC execution reports (summary, scope, results, risks, next steps) |
| `failures/` | Failure analysis reports (classification, root cause, healing suggestions) |
| `audit/` | Audit trail entries (AI actions, human approvals, promotions, guard events) |

## Report Format

All QC reports follow the standard format defined in `packages/ai/qc-report-template.md`:

- Summary
- Request
- Scope
- Context Read
- Impact Analysis
- Test Plan Used
- Tests Generated
- Tests Executed
- Failures
- Healing Suggestions
- External Systems Verified
- Not Verified / Risks
- Audit Trail
- Next Steps
