# test-assets/ — Test Code Asset Lifecycle

This directory manages the lifecycle of generated test code assets.

## Asset Lifecycle

```
generated/  →  reviewed/  →  promoted/  →  deprecated/
```

| Stage | Location | Description |
|-------|----------|-------------|
| **Generated** | `generated/` | Test code generated by AI. Initial, unreviewed. NOT for CI regression. |
| **Reviewed** | `reviewed/` | Human-reviewed test code. Approved for promotion consideration. |
| **Promoted** | `promoted/` | Stable, reviewed tests that run in CI regression. Long-term assets. |
| **Deprecated** | `deprecated/` | Tests that are obsolete, replaced, or no longer relevant. Retained for audit. |

## Promotion Rules

1. **Generated assets** CANNOT be directly promoted.
2. **Review requires**: human verification that tests are correct, assertions are valid, and no business rules are fabricated.
3. **Promoted assets** are the ONLY tests that run in stable CI regression.
4. **Deprecation** requires a reason and archive date.

## Promoting an Asset

```bash
npm run promote:test-asset -- --source=generated/<asset> --target=reviewed
```

The `promote-test-asset.ts` script enforces lifecycle rules:
- Generated → Reviewed (requires review confirmation)
- Reviewed → Promoted (requires explicit promotion flag)
- Any → Deprecated (requires deprecation reason)
